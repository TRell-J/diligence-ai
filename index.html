Responsible-AI & Governance
How this tool handles data, risk, and accountability
EU AI Act posture

A diligence summarizer is a limited-risk system: its obligation is transparency. The UI labels all output as AI-assisted, marks model claims that lack verbatim evidence, and keeps a human in the loop. It is not used for prohibited or high-risk purposes (e.g. credit scoring of individuals).

Data protection (GDPR)

Heuristic mode processes documents entirely in-browser — no upload, no server, no retention. With a BYO API key, only the prompt + extracted text are sent to the provider you choose, after an explicit authorization checkbox. No personal data is stored by the app.

Data residency & confidentiality

No backend means no third-party data custody by default. A confidentiality gate blocks any external model call until the analyst confirms authorization — the control point for NDA / data-room material.

Hallucination guardrails

Financial metrics, scores and benchmarks are computed deterministically from the source — never taken from the model. Each model-supplied evidence quote is verified to exist verbatim in the document; unverifiable claims are flagged for manual review.
